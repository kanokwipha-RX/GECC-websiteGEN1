# GECC Sisaket 2570

Government service-centre assessment for 28 organizations across six MENTOR groups.
This is an existing assessment application, not an LMS. Preserve all assessment
criteria, scoring, review/return/reopen flows, evidence and reporting functions.

The owner approved incremental refinement of the current identity and Thai font,
central data storage on an agency Ubuntu server, public aggregate statistics only,
six-digit internal organization usernames plus passwords, and individual reviewer
accounts. Never deploy, import real data, or change domain criteria implicitly.

Public content: committee, library links, group imagery. Assessment details and
attachments require resource-scoped authorization. Shared organization accounts
identify an organization, not an individual. Source commit: 4606a5f.
