# SISAKET GECC PROJECT · GEN 1

ระบบติดตามและตรวจประเมินมาตรฐานศูนย์ราชการสะดวก (GECC) ประจำปี พ.ศ. 2570 จังหวัดศรีสะเกษ

พัฒนาและดูแลระบบ: Kanok_rx · สำนักงานสาธารณสุขจังหวัดศรีสะเกษ

## ไฟล์ในโปรเจกต์

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | แอปทั้งหมดในไฟล์เดียว (HTML + CSS + JavaScript) |
| `data/sisaket-gecc-2570-units-28.json` | รายชื่อหน่วยบริการที่สมัคร 28 แห่ง 6 กลุ่ม MENTOR |

## ความสามารถหลัก

- **Executive Dashboard** ภาพรวมจังหวัด นับถอยหลังวันปิดรับสมัคร (25 ธ.ค. 2569) ความพร้อม 3 ด้าน กราฟกายภาพ 15 ข้อ ผลการตรวจจาก MENTOR และผลสำรวจความพึงพอใจ/ความเชื่อมั่น
- **MENTOR** (6 กลุ่ม + ผู้ประสานงานจังหวัด) งานรอตรวจ ตรวจให้คะแนน ข้อเสนอแนะรายข้อ ส่งกลับแก้ไข ยืนยันและล็อกผล เปิดแก้ไขใหม่พร้อมเหตุผล ประวัติการตรวจ
- **หน่วยบริการ (MENTEE)** DASHBOARD สถานะ ส่งข้อมูลให้จังหวัด แนบรูป/PDF ส่งเอกสารด่วนให้ MENTOR
- **แบบสรุปผลการตรวจประเมิน** ดาวน์โหลดเป็น PDF ได้

## วิธีเปิดใช้งาน

- เปิด GitHub Pages: **Settings › Pages › Branch: `main` / root** แล้วเปิดลิงก์ที่ GitHub สร้างให้

## ข้อจำกัดของ GEN 1 (เวอร์ชันต้นแบบ)

- ข้อมูลและไฟล์แนบเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage / IndexedDB) ยังไม่มีฐานข้อมูลกลาง
- PIN เข้าสู่ระบบเป็นแบบสาธิต ยังไม่ใช่ระบบรักษาความปลอดภัยจริง
- ตัวเลขในหน้าแรกเป็นข้อมูลจำลอง ล้างได้ที่ MENTOR › จัดการข้อมูล (ผู้ประสานงานจังหวัด)
- ก่อนใช้งานจริงควรเชื่อมฐานข้อมูลกลาง ที่เก็บไฟล์ และระบบเข้าสู่ระบบที่ตรวจสิทธิ์บนเซิร์ฟเวอร์
