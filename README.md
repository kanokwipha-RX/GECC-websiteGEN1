**รันบนโฮสต์จริง:** อัปโหลดชุด public และ gecc-private ตาม [คู่มือ PHP](PHP-DEPLOYMENT-TH.md)

- ส่งออกพร้อมไฟล์แนบได้ ส่วนการนำเข้าระบบกลางมี preview และป้องกันแทนที่ข้อมูลเดิม

## ความสามารถหลัก

- **Executive Dashboard** ภาพรวมจังหวัด นับถอยหลังวันปิดรับสมัคร (25 ธ.ค. 2569) ความพร้อม 3 ด้าน กราฟกายภาพ 15 ข้อ ผลการตรวจจาก MENTOR และผลสำรวจความพึงพอใจ/ความเชื่อมั่น
- **MENTOR** (6 กลุ่ม + ผู้ประสานงานจังหวัด) งานรอตรวจ ตรวจให้คะแนน ข้อเสนอแนะรายข้อ ส่งกลับแก้ไข ยืนยันและล็อกผล เปิดแก้ไขใหม่พร้อมเหตุผล ประวัติการตรวจ
- **หน่วยบริการ (MENTEE)** DASHBOARD สถานะ ส่งข้อมูลให้จังหวัด แนบรูป/PDF ส่งเอกสารด่วนให้ MENTOR
- **แบบสรุปผลการตรวจประเมิน** ดาวน์โหลดเป็น PDF ได้
- **GECC Library** คลังเอกสารแยกตามโฟลเดอร์ใน Google Drive พร้อมภาพปกจากเอกสารจริง การ์ดโปร่งใส และเอฟเฟกต์เมื่อชี้เมาส์หรือใช้คีย์บอร์ด
- **คณะทำงาน** ที่ปรึกษาคณะทำงานอยู่เหนือรายชื่อ 12 ตำแหน่ง พร้อมอำนาจหน้าที่ร่วม 4 ข้อ ช่องรูปที่รอเพิ่มเติม และไฟล์คำสั่ง PDF
- **เข้าสู่ระบบ** เริ่มด้วย 3 ช่องทาง: ที่ปรึกษา MENTOR → เลือกชื่อ, MENTOR → เลือกกลุ่มและชื่อ, หน่วยบริการที่สมัคร → เลือกกลุ่มและหน่วยบริการ จากนั้นกรอกรหัสผ่าน ระบบจริงใช้บัญชีที่มีอยู่ตามสิทธิ์เซิร์ฟเวอร์
- **MENTOR** แสดง 24 คน เรียงตาม DOCX ฉบับแก้ชื่อ พร้อมภาพที่จับคู่ตามบุคคล
- **Gallery** มีภาพกิจกรรมวันที่ 29 ตุลาคม 2569 ครบ 42 ภาพ คลิปกิจกรรมและลิงก์สำรวจจริงรอยืนยัน

เมนูหลักเรียงเป็น หน้าหลัก → คณะทำงาน GECC → MENTOR → Library → Gallery → เข้าสู่ระบบ
คู่มืออัปเดตข้อมูลเดิมโดยคงบัญชี/ผลประเมินอยู่ใน [RELEASE-ROSTER-2570-TH.md](RELEASE-ROSTER-2570-TH.md)
การเลือกชื่อช่วยกรอกบัญชีที่ผูกตรงกันแล้วเท่านั้น ไม่เปลี่ยนสิทธิ์และไม่เดาบัญชีจากลำดับรูป

หน้า GECC Library, คณะทำงาน และ Portfolio ใช้หัวข้อขนาดใหญ่พร้อมไอคอนและการ์ดโปร่งใสในแนวทางเดียวกัน มีแสงตามเมาส์ สถานะโฟกัสสำหรับปุ่มและลิงก์ และรองรับการลดการเคลื่อนไหว ภาพบุคคลและภาพกลุ่มแสดงเต็มโดยไม่ซูมตัดข้อความในภาพ

## การใช้ดีไซน์การ์ด React ในอนาคต

เว็บรุ่นนี้เป็น HTML, CSS และ JavaScript ใน `index.html` ไฟล์เดียว โดย CSS อยู่ในแท็ก `<style>` ยังไม่มี React, TypeScript, Tailwind CSS, shadcn/ui หรือโฟลเดอร์คอมโพเนนต์ จึงใช้ `card-21.tsx` ที่แนบมาในเว็บรุ่นนี้โดยตรงไม่ได้ หากจะย้ายเว็บไปใช้ React ให้สร้างโปรเจกต์ใหม่ตาม [คู่มือ shadcn/ui สำหรับ Vite](https://ui.shadcn.com/docs/installation/vite):

```bash
npx shadcn@latest init -t vite
# เลือกชื่อโปรเจกต์และทำตามคำถามของ CLI จากนั้นเข้าโฟลเดอร์โปรเจกต์ใหม่
npm install lucide-react
```

CLI จะสร้างโครง React + TypeScript พร้อมตั้งค่า Tailwind CSS และ shadcn/ui ให้ หากเริ่มจาก Vite React + TypeScript ที่มีอยู่แล้ว ให้ติดตั้ง Tailwind ด้วย `npm install tailwindcss @tailwindcss/vite` เพิ่มปลั๊กอินใน `vite.config.ts` และ `@import "tailwindcss";` ใน `src/index.css` แล้วตั้งค่า alias `@/*` และรัน `npx shadcn@latest init` ตามคู่มือข้างต้น

ในโครง Vite ที่ใช้ alias `@` ชี้ไปที่ `src` ให้เก็บคอมโพเนนต์เป็น `src/components/ui/card-21.tsx` ตัวอย่างใช้งานใน `src/App.tsx` และสไตล์รวมใน `src/index.css` โฟลเดอร์ `src/components/ui` จำเป็นเพื่อให้ import `@/components/ui/card-21` และค่า `aliases.ui` ใน `components.json` ชี้ไปที่ไฟล์เดียวกัน หากต้องการใช้ `/components/ui` ที่รากโปรเจกต์จริง ให้เปลี่ยน alias `@` ใน TypeScript/Vite และ `aliases.ui` ให้ตรงกันตาม [คู่มือ components.json](https://ui.shadcn.com/docs/components-json)

## ข้อจำกัดของ GEN 1 (เวอร์ชันต้นแบบ)

- ข้อมูลและไฟล์แนบเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage / IndexedDB) ยังไม่มีฐานข้อมูลกลาง
- PIN เข้าสู่ระบบเป็นแบบสาธิต ยังไม่ใช่ระบบรักษาความปลอดภัยจริง
- ตัวเลขในหน้าแรกเป็นข้อมูลจำลอง ล้างได้ที่ MENTOR › จัดการข้อมูล (ผู้ประสานงานจังหวัด)
- ก่อนใช้งานจริงควรเชื่อมฐานข้อมูลกลาง ที่เก็บไฟล์ และระบบเข้าสู่ระบบที่ตรวจสิทธิ์บนเซิร์ฟเวอร์
